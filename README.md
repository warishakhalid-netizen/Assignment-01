## Project Overview

- About Me

- Contact Me

## Colour Scheme
I used Adobe Color to choose a colour scheme that creates a soft, cute, and cohesive appearance.

- Dusty Rose: #B38B92
- Deep Mauve Brown: #735A5E
- Soft Blush Pink: #F2BDC7
- Light Cotton Candy Pink: #FFC7D1
- Muted Rose Pink: #D9A9B2

**Adobe Color scheme type:** ["Abstract colored paper texture background. Minimal geometric shapes and lines in pastel pink, light blue and green colours"]

## Responsive Design
I created three CSS files to adapt the website to different screen sizes.

- **Mobile:** 480px and below. Smaller images, text, and spacing help the website fit phone screens.
- **Tablet:** 481px–960px. Adjusted sizing and spacing help the content fit medium-sized screens.
- **Laptop/Desktop:** 961px and above. The layout uses the additional space available on larger screens.

The CSS files are 'mobile.css', 'tablet.css', and 'laptop.css'. I used media attributes in my HTML stylesheet links to select the appropriate file based on screen width.

## Gradients
- **Projects page:** An angled linear gradient using '135deg' and the colours pale pink and dusty rose.
- **Contact Me page:** A linear gradient transitioning from pale pink to dusty rose from top to bottom.
